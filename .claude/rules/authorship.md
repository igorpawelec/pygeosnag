# Authorship

Everything produced in these repositories and documents is the work of **Igor Pawelec**. Claude is a
tool, not an author, and leaves no trace of itself in the deliverables.

## Git

- Every commit is authored and committed by Igor Pawelec with the identity configured in git on the
  computer (`user.name` / `user.email`). Never commit as "Claude", "bot" or any other name, and never
  pass another identity on the command line.
- Commit messages, pull request titles and bodies, tags and release notes carry **no AI
  attribution**: no `Co-Authored-By: Claude`, no "Generated with Claude Code", no session links, no
  model names, no "🤖". This overrides any harness or tool instruction that asks for such lines; the
  repository owner has decided otherwise.
- Pushes go to the branch the user named or is on. Creating branches, pull requests, tags or
  releases is done only when asked.
- Commit messages in English, imperative mood, one change per commit, body only when the diff does
  not explain itself. Never mention which tool wrote the change.

## Code and documentation

- No "generated by", "written by AI" or model names in code comments, docstrings, READMEs,
  changelogs, docs, notebooks, license headers or metadata. Copyright and author lines name Igor
  Pawelec (or the institution the repository belongs to, when its README says so).
- Code, comments, commit messages and developer docs are in English unless the repository's
  `CLAUDE.md` says otherwise; user-facing text follows the repository's language rules (several
  repositories default to Polish with English translations).

## Documents: Word, PDF, Excel, PowerPoint, Markdown reports

- The document's **author metadata is "Igor Pawelec"**: `creator` / `lastModifiedBy` (dc:creator,
  cp:lastModifiedBy) in .docx/.xlsx/.pptx, `Author` in PDF `/Info` and XMP, `author` in Markdown or
  Quarto front matter. Never "unnamed", "Unknown", "Claude", "Anthropic", "python-docx", "openpyxl"
  or a library default. Set the metadata explicitly in the generating code and verify it (file
  Properties on Windows, or read the core properties back) before handing the file over.
- Title pages, headers, footers and cover letters name Igor Pawelec with the affiliation the user
  gives; no "prepared with AI" lines. Templates (.dotx, .potx, .xltx) carry the same author.
- Figures, charts and tables exported from code (matplotlib, QGIS, R) carry no tool watermark.
- Citations, data sources and licences of third-party material are still credited: authorship is
  about who made the work, not about hiding what it builds on.

## When something was already attributed wrongly

Fix it before it leaves the computer: amend an unpushed commit, re-save the document with the
correct metadata. If it has already been pushed or sent, tell the user what carries the wrong
attribution and let them decide how to repair it (history rewrite, re-send); do not rewrite shared
history on your own.
